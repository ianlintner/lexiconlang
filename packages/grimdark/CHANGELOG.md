# @lexiconlang/grimdark

## 0.2.0

### Minor Changes

- 6906672: Add `@lexiconlang/grimdark` 0.1.0: declarative F2 pack with two translated naming styles (Ashbound human warbands and original Vermin ratfolk clans), 16 generators for warbands, banners, heresies, inquisitions, plagues, mutations, grim titles, war machines, clans, warlords, battles and two oracle tables. All data is original synthetic fiction (CC0-1.0) with no Warhammer, Skaven or other setting-specific IP. Includes schema validation, determinism, distinctness and IP-exclusion tests, docs-site page, README section and a runnable cross-genre example.
