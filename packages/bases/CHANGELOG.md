# @lexiconlang/bases

## 0.2.0

### Minor Changes

- 7609b94: Add `@lexiconlang/bases` with six real-language-inspired base descriptors (Norse, Celtic, Latin, Greek, Japanese, Arabic) exposed as tree-shakeable subpaths. Each base includes phonotactics, orthography/romanization, naming structures and literal placeholders, plus an F2-compatible pack manifest at `data/<slug>/<slug>.pack.json`. All data is original CC0 with a provenance and sensitivity note.
- 2f35496: Add ten B2 base languages (slavic, old-english, persian, sanskrit, mandarin, nahuatl, yoruba, polynesian, ancient-egyptian, finnish) using the unchanged B1 framework. Mandarin/Yoruba/Polynesian add opt-in tone-mark orthographies with ASCII romanization fallback; Polynesian uses CV-only phonotactics. All data is original CC0-1.0 with provenance and sensitivity notes; existing B1 output is untouched.
